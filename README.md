# Octo-Podium Studio Web Page 🐙🍳
Official web page of Octo-Podium Studio. This project serves as the central landing page and portfolio for our growing collection of indie game titles, beginning with our first game, a cooperative puzzle experience: Rangolithical.

## 🕹️ Featured Project: Rangolithical

Teamwork: Designed up to two players (Local/Online).

Unique Mechanics: Control characters with specialized tools (Fork hooks & Giant pans).

The Food Tower: Navigate levels filled with "monstrous" ingredients and magical recipes.

## ⚡ Tech Stack
- HTML5
- CSS3
- Javascript
- Integrated Font Awesome 6 (Brands & Solid)
